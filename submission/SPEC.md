# 《豬事不妙！》V1-14 成品規格說明

本規格描述目前 V1-14（`feature/pig-game`）的可玩成品，對應遊戲程式版本 `d0351a9`。不是舊版植物遊戲規格，也不把尚未完成的 V2 動畫列為已完成功能。

## 一、作品定位與故事

- 名稱：豬事不妙！／The Great Pig Escape。
- 類型：三關、單人、電影敘事風格的點擊解謎遊戲。
- 使用情境：電腦瀏覽器，以滑鼠點選為主，提供全螢幕；無須帳號或安裝套件。
- 設計目標：每個畫面只有一個主要任務，選項清楚，操作後立即給予故事、圖像與聲音回饋。

富豪的 AI 無人智能車在大雨中故障翻覆，車上唯一乘客是一頭戴著金項鍊、身價上億的冠軍神豬。玩家扮演受委託尋豬的保鑣，沿足跡進入森林，發現神豬與記者克里斯・培根被虛構的奇幻部落困在洞穴。救援後，神豬不願回家，玩家必須判斷食物與行動，最後選擇領取賞金，或讓牠在遠離部落的田野湖畔獲得自由。

## 二、畫面流程與操作規格

標題 → 五幕前導 → 第一關辨認足跡 → 過關畫面 → 第二關救援 → 過關畫面 → 第三關食物選擇 → 湖畔抉擇 → 雙結局。

標題提供開始遊戲、重看故事，以及有實際進度時才出現的繼續遊戲。開始遊戲直接播放序幕，不顯示覆寫確認；已有進度先保留一份備份。前導是以原創分鏡製作的 20 秒內嵌 MP4，搭配字幕與淡入淡出，不宣稱是完整逐格角色動畫。可播放、略過，並於片尾點選開始第一關。

主要畫面為大幅場景、上方任務、下方繁體中文字幕與大型選項。使用原創游標，互動熱區跟隨場景尺寸。右上方提供玩法、聲音、裝置配音、環境微動、全螢幕與主選單控制。

## 三、關卡、成功與失敗條件

| 關卡 | 玩家實際操作 | 成功條件 | 錯誤／失敗回饋 |
|---|---|---|---|
| 第一關：森林岔路 | 點選鹿、豬或熊的足跡，觀察線索後決定前進 | 選到有金飾線索的豬蹄印，找到洞穴 | 鹿路線走錯山頭；熊路線顯示保鑣使用防熊噴霧撤退。失敗後可重新選足跡 |
| 第二關：洞口救援 | 先與記者對話，選擇如何引開守衛，再點救援刀熱區割斷兩者身上的繩索 | 開羊圈讓守衛忙著收羊，救出神豬與記者 | 直接割繩或用木棒嚇退守衛會被抓；只救豬就離開，記者呼救引來守衛。重試保留對應救援步驟 |
| 第三關：回家的條件 | 打開記者背包，從野果、漢堡、草莓蛋糕中選擇，再做最後決定 | 選漢堡，神豬吃完後乖乖同行，到安全湖畔選擇結局 | 野果讓豬生氣跑回森林；蛋糕使牠興奮撲倒保鑣，聲響引來部落。重試直接回食物選擇，不重播開包演出 |

最終 A「富豪結局」：保鑣與記者領到賞金，神豬戴回皇冠與項鍊，仍帶無奈表情。最終 B「自由結局」：在遠離部落的湖畔取下項鍊，保鑣、記者和神豬一起入鏡。兩種結局皆屬通關，提供再玩一次及返回主選單。

## 四、技術、存檔與限制

1. 遊戲主體為單一 `index.html`，原生 HTML、CSS、JavaScript；圖片和 MP4 以 data URL 內嵌，聲音由 Web Audio API 合成。
2. 執行時不需 React、Vue、npm、Node.js、外部 CDN、字型、圖片網址、音效檔或後端。GitHub Pages 可供應這份靜態 HTML。
3. localStorage 儲存關卡進度、解鎖章節、完成結局與聲音設定；屬於同一瀏覽器的本機存檔，不是雲端帳號存檔。
4. 繼續遊戲回到關卡檢查點；已完成遊戲則回到結局。失敗時的再試一次，依目前步驟重試，與重新載入關卡的存檔行為不同。
5. 操作有狀態檢查與短暫連點鎖；解繩不會重複計入、過關後需點下一關，並處理損壞或無法使用的存檔。
6. 配樂第一次由玩家互動啟動，可關閉。台灣華語朗讀僅在裝置安裝本機 zh-TW 語音時提供；未安裝仍可使用字幕與原創合成聲音，沒有包裝成真人配音。
7. 保留桌面構圖，不把手機版最佳化或 V2 全角色動畫列為本次成果。首次載入含內嵌媒體，需等待檔案載入。

## 五、美術、聲音與原創紀錄

所有場景以本專案 AI 原創圖生成／編修，足跡、互動標示、游標與少量環境微動由程式繪製。不下載網路遊戲、電影、角色圖片，不指定模仿既有作品、藝術家或真人演員；未使用外部音樂包。配樂、煞車、動物叫聲、警戒等聲音採原創 Web Audio 合成。

保鑣在全部 11 張相關圖中統一為小眼銳利、鷹勾鼻、黑色開襟衫與頭頂墨鏡的成熟角色；記者保留較年輕、大眼睛、髒污受困的造型。原圖檔名、提示詞摘要與 SHA-256 紀錄見根目錄 `ART_SOURCES.md`。這是可查閱的創作來源紀錄，不把 AI 生成當成法律上的零侵權保證。

## 六、AI 協作與反覆修改

使用者提出故事、操作和美術要求；AI 協助實作、產生原創素材、檢查程式並依回饋修改。過程包括：將複雜的植物模擬器改為三關點擊冒險；改以放羊引開守衛；修正第一次開局誤判覆寫、字幕遮擋足跡、重複過關演出與重試回錯步驟；統一角色與服裝；替換低解析度圖；修正前導影片殘留的背包豬；調整字幕、按鈕、游標及結局構圖。Git 提交紀錄保留這些修正，不宣稱為完全未使用 AI 的作品。
