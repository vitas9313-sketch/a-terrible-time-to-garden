# 豬事不妙！The Great Pig Escape

原創三關點擊冒險。執行檔僅 `index.html`：內嵌HTML/CSS/JavaScript、WebP圖像與MP4，無建置、外部CDN、字型、API或後端。GitHub Pages選 `feature/pig-game` 分支根目錄。舊植物遊戲保留在 `feature/milestone-1`。

## 現行故事與操作

- 序幕：冠軍豬是富豪AI無人智能車的唯一乘客。暴雨中系統故障、車輛翻覆，豬逃進森林；富豪委託玩家活著找回牠。約20秒內嵌MP4，由五幕全新原創分鏡、推鏡與轉場剪輯，並非逐格角色動畫。可重看、略過；減少動態偏好改為靜態分鏡。
- 第一關：比較鹿、豬、狼的連續足跡與金飾線索，再決定方向。足跡已放大、增加淺色外緣與深色印痕；正確方向進山洞，錯誤方向有短演出與失敗重試。
- 第二關：先低聲與《山城日報》記者克里斯・培根對話。他因憂鬱症休長假，原想在森林散心卻被拘禁；此背景不作笑點。畫面可見洞外羊圈，鬆開插銷使守衛忙著收羊，比投石合理。貿然救援／威嚇守衛會失敗。玩家可選先救豬再離開；若棄救記者，他會急得呼救，引回守衛並使任務失敗。兩者均救出才可過關。
- 第三關：先打開獲救記者的背包，交代漢堡／蛋糕是午餐點心，野果是採集物，再選大型同風格食物。野果使豬逃走；蛋糕使牠冒愛心撲倒玩家，引來追兵；漢堡讓牠安靜跟隨。之後一行人走到遠離部落、靠近富豪莊園的田野湖畔，才決定領賞或放牠自由。自由結局由記者聯絡湖畔照護站安排照護，避免在部落旁放生又被抓。
- 所有成功與失敗先有約1.8秒鏡頭推近／分鏡短演出，再進結算。蛋糕事件另外包含愛心、撲近與包圍。演出不提供一般操作；回主選單後不會被延遲計時誤切回結果。

## 介面與聲音

字幕改為大型電影字幕，電腦版約22–44px，使用本機宋體／明體與系統備援字型、描影與深底。無外部字型下載。細指標裝置使用本作原創56px冒險游標；觸控保留一般操作。食物為同電影動畫風格的新生成圖像，放大並加上明亮邊緣。

按鈕與提示都在遊戲螢幕內，支援全螢幕與Esc退出。本版固定維持電腦16:9構圖，不採用直向手機專用排版；以電腦瀏覽器與全螢幕為主要操作方式。結局THE END使用大型粗體；任務失敗有「再試一次」。

Web Audio配樂全由本作新寫音序與振盪器合成，未取用或參考任何既有曲目：標題／序幕緊張低音、森林探索、洞穴潛行、引豬輕節奏、危機、結局溫暖旋律。煞車聲由噪音、濾波及振盪器合成，在序幕車禍前觸發。首次互動後播放；可靜音，切場景不疊播，頁面隱藏時停止。

## 存檔

localStorage只記錄版本、關卡檢查點、已解鎖關卡、結局及聲音設定；不讀寫植物遊戲存檔。關卡中途重整會重回該關開場，第二關會重新聽記者介紹，第三關會重新開背包。開始新遊戲有明確覆寫確認，取消不變更存檔。損壞或不可用的儲存不會使整款遊戲崩潰。

## 本輪實際測試

以Python Playwright操作系統Chromium，經本機靜態HTTP：

- 原創MP4實際解碼、約20秒、字幕切換、煞車聲觸發旗標、播放完進第一關入口。
- 記者三段介紹、羊圈成功、貿然救援失敗、只救豬後棄救記者失敗、兩者獲救過關；可先救記者再救豬。
- 開背包後才出現食物；野果失敗、蛋糕愛心／追兵失敗、漢堡成功；湖畔富豪／自由雙結局。
- 成功／失敗演出、重試、離開畫面取消延遲判定、結局恢復。
- 五種場景配樂狀態切換、煞車合成觸發；全螢幕進出與切關維持。
- 390×844手機走完第二、三關與結局，字幕至少20px，食物熱區至少80px寬，無水平溢出。已檢視桌面足跡／食物、手機記者畫面。
- 測試期間無JavaScript錯誤。

未驗證：實體手機、其他瀏覽器、實際GitHub Pages部署、file://開檔、音樂人工聽感及5–8分鐘真人時長。短演出是圖片／CSS動畫，不宣稱完整角色動作影片。AI圖像仍可能有少量角色細節差異。

## 素材與檔案

背景與食物均為本次image_gen全新原創圖像或本專案原創圖的編修；足跡、游標、介面與音效為程式原創。未下載現有電影、遊戲、美術或音樂。詳見 [ART_SOURCES.md](ART_SOURCES.md)。單檔因內嵌高解析媒體約18.5MB，桌面大螢幕仍受來源圖解析度限制。

看程式：GitHub切換 `feature/pig-game` → `index.html`。玩遊戲：下載該分支ZIP，解壓後取得單檔；或設定Pages到同分支根目錄。推送成功不等於Pages已部署。

## 電腦版、重試檢查點與清晰度更新

- 記者更名「克里斯・培根」，稱呼與對話一致更新。
- 點「再試一次」不再重播記者介紹或打開背包：守衛選擇失敗回守衛選項；棄救記者失敗回救援選擇並保留已救出的豬；食物失敗直接回三種食物。重新載入頁面仍依關卡檢查點恢復，與局部重試分開。
- 繩索改為覆蓋身體範圍的大型繩束熱區，配救援刀提示、切割回饋；救出後切換無繩狀態，不能重複操作。
- 封面、森林岔路、引豬與雙方受綁的割繩場景重製為1672×941的單幅原創圖（前三張原來源為682×384），WebP品質提高至94；前導重新編碼為1920×1080／CRF19。輸出1080p不代表所有舊分鏡來源皆為原生1080p。
- 移除直向手機專用重排，所有視窗沿用電腦16:9構圖。

本輪Chromium實測：守衛失敗重試不回介紹、棄救重試保留已救出的豬、野果／蛋糕失敗重試直接回食物、刀具切割熱區、割繩救援與結局，以及窄視窗維持16:9。無JavaScript錯誤。

高解析驗證：Chromium實際載入四張關鍵圖，naturalWidth均至少1600px；前導實際解碼1920×1080並能觸發煞車聲。全螢幕切關保持正常，刀具游標正常，無JavaScript錯誤。部分舊分鏡／救援狀態圖仍沿用既有解析度，未宣稱全素材重新製作或原生4K。
