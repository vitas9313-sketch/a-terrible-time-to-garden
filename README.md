# 豬事不妙！The Great Pig Escape

三關原創點擊冒險，單一 `index.html`，可由靜態網站／GitHub Pages 提供；無建置、外部圖像、API、字體或音檔依賴。原植物遊戲保留在 `feature/milestone-1`。

## 本版更新

- 原創 AI 場景：冠軍封面、山路運輸、車禍、富豪來電、洞穴預告、森林岔路、洞穴救援狀態、森林出口、豪宅與自由結局。米白／墨綠介面，移除物件旁的文字牌，讓場景成為主體。
- 約 15 秒真正 MP4 前導：五幕原創分鏡，以推鏡／淡入淡出剪輯，內嵌 data URL。這是電影式分鏡剪輯，不是逐格角色動畫；音樂由 Web Audio 同步播放。支援繼續播放、略過、重看；減少動態偏好改用有字幕的靜態分鏡。
- 第一關：左鹿蹄、中豬蹄、右狼爪，共三列連續足跡從前景深入森林。先觀察足印形狀與金飾／獸毛線索，再決定沿哪條路走；移除直接標出動物名稱的選項牌。
- 第二關：石頭投向洞外，守衛去檢查聲響，才可解開兩個繩結。直接解繩或拿木棒衝向守衛會被捕，切換被綁上未點火烤架的任務失敗畫面；不血腥。守衛不再追香蕉。解繩前後使用不同場景圖。
- 第三關：登山客先交代這頭富豪豬只接受漢堡／草莓蛋糕，兩者都能取得信任。野果會使牠憤怒逃回森林，切換任務失敗畫面。可重試本關，豪宅／自由兩種最終選擇都是有效結局。
- 保留音樂、音效、關卡存檔、重試、結局恢復與基本鍵盤操作。

## 美術來源

所有背景是本次透過 image_gen 全新生成的原創動畫電影風格場景，未下載任何現有作品或外部素材。足跡、互動物件、介面為程式原創 SVG/CSS；音樂及音效為 Web Audio 原創合成。背景以 WebP 內嵌，前導以 H.264 MP4 內嵌；不需要其他本地檔案。

生成來源與處理紀錄見 [ART_SOURCES.md](ART_SOURCES.md)。檔案大小因內嵌媒體增加至約 3–4 MB；來源場景解析度主要為 682–836px 寬，適合遊戲首版，桌面超大畫面仍可見細節解析度限制。人物跨鏡頭的細節仍可能有少量 AI 生成差異。沒有宣稱已做真正 3D 角色動畫。

## 本版實際測試

以 Playwright 操作 Chromium，透過本機靜態 HTTP：

- MP4 實際解碼、960×540／約15秒、播放時間前進、字幕依時間軸切換、播放完進入第一關入口；略過及重看不覆寫存檔。
- 第一關三列足跡觀察；鹿／狼追蹤失敗可重試；豬蹄通關。鍵盤可聚焦及觀察足跡。
- 第二關投石成功；直接解繩與衝向守衛兩種失敗；雙繩必須各點一次，重複點擊不重複計數；解繩圖片依狀態變化。
- 第三關野果任務失敗、漢堡／蛋糕各自成功；富豪／自由雙結局；第一關完成後重整進入第二關，結局重整恢復，損壞存檔安全回標題。
- 音樂開關與單一播放迴圈；390×844 實際點擊足跡並走完整三關，無水平溢出。減少動態使用靜態分鏡與字幕。
- 測試期間未觀察到 JavaScript 錯誤。已修正離開影片時舊時間事件存取不存在字幕的問題。

未驗證：實體手機、其他瀏覽器、實際 GitHub Pages 部署、file:// 直接開啟及配樂人工聽感。

## 看新版
