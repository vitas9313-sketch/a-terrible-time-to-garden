# 豬事不妙！The Great Pig Escape

三關點擊劇情遊戲。單一 `index.html`，無外部圖片、字體、套件、API 或後端。GitHub Pages 可選此分支根目錄，不需建置。

## 已完成

- 五幕前導：冠軍、運輸、車禍、來電、洞穴預告；每幕約 3.2 秒，自動轉場、下一幕、略過、重看。
- 第一關：鹿印與鞋印錯誤提示，大豬蹄印成功找到洞穴。
- 第二關：香蕉或木棒引開守衛，石頭被發現可重試；神豬及旅人繩結各點一次才能過關。
- 第三關：胡蘿蔔與漢堡錯誤可重試，草莓蛋糕取得信任；選回豪宅或自由，兩者都算完成。
- 明確成功畫面、下一關、局部重試、主選單、覆寫存檔確認、關卡檢查點、結局恢復、音樂控制。
- 配樂：Web Audio 原創八音循環旋律及低音，依關卡調整速度／音色；合成點擊、錯誤、豬叫與成功音效。首次互動後播放，隱藏頁面暫停，切畫面取消舊播放迴圈；靜音會停止已排程音符。

## 美術來源與限制

全部場景及角色為本次以 SVG/CSS 程式原創繪製，無網路素材或第三方圖示。跨場景共用同一神豬繪圖，金項鍊在自由結局移除。這是原創佔位美術，**尚未達電影動畫正式完稿質感**，也沒有宣稱 AI 生成圖像。

待補正式原創圖片：五幕前導（冠軍、山路運輸、非血腥車禍、富豪來電、洞穴預告）、森林腳印場景、守衛營地及解繩前後狀態、出口親近神豬、豪宅與自由結局。之後生成時需保留提示詞與來源紀錄，壓縮後以 data URL 嵌入本檔。不得下載或模仿既有作品。

## 實測紀錄

以 Python Playwright 操作系統 Chromium，經本機靜態 HTTP 載入：

- 五幕前導手動推進、自動切幕、略過及重看不覆寫既有進度。
- 第一關兩種錯誤／成功；第二關石頭重試、香蕉／木棒成功、雙繩結及重複點擊防護；第三關兩個錯誤食物、蛋糕成功、A／B 兩種結局。
- 第一關完成後重整，繼續遊戲進入第二關；結局重整後正確恢復；損壞 JSON 安全回到標題。
- 音樂開／關控制播放迴圈；AudioContext 進入 running 狀態。未做人工聽感評估。
- 390×844 手機視窗完整通關，熱區至少 44px，無水平溢出；手機字幕遮擋熱區問題已修正。已檢視手機結局截圖。
- 測試期間無 JavaScript 錯誤，未產生外部網路請求。

未驗證：實體手機、其他瀏覽器、實際 GitHub Pages 部署及 file:// 直接開檔。主流程刻意很短，尚未做 5–8 分鐘真人遊玩時長驗證，不靠倒數或長對話拉長時間。正式美術與配樂聽感仍待補強。
